Terminal and vim

Bash basics, a first look at vim, and — later — SSH

Author

MECH 501/600 — Computational Turbulence

Published

September 22, 2026

NoteTwo ways to get a terminal

The default for this course is the terminal built into JupyterLab — it is already a shell on the cluster, with nothing to install. Connecting from a terminal on your own computer over SSH is a more advanced option we introduce at the end of this page.

1 The terminal

In JupyterLab click the + (new Launcher) and choose Terminal (or File ▸ New ▸ Terminal). You now have a bash shell running on the cluster — the same place your notebooks and files live.

1.1 Getting around and looking at files

A handful of commands cover almost everything you need:

pwd                 # print working directory — where am I?
ls                  # list files here
ls -l               # long listing: sizes, dates, permissions
ls -a               # also show hidden files (names starting with a dot)
cd project          # go into a folder
cd ..               # go up one level
cd ~                # go to your home directory
mkdir runs          # make a new folder

Looking inside a file without opening an editor:

cat  log.simpleFoam              # print the whole file
less log.simpleFoam              # page through it (Space scrolls, q quits)
head log.simpleFoam              # first 10 lines
tail log.simpleFoam              # last 10 lines
tail -f log.simpleFoam           # follow a file as it grows (Ctrl-C to stop)
grep "converged" log.simpleFoam  # show only lines containing a word

Copying, moving and deleting files:

cp file.txt backup.txt   # copy
mv old.txt new.txt       # rename / move
rm scratch.txt           # delete — there is no undo
Tip

Press Tab to auto-complete file and folder names, and the ↑ / ↓ arrow keys to scroll back through commands you already typed.

1.2 Make your shell nicer (optional)

~/.bashrc runs every time you open a shell. The minimal setup below gives a readable two-line prompt, a longer timestamped history, and safer rm/cp/mv. Create it with vim ~/.bashrc, paste, save, then run source ~/.bashrc to apply it in the current shell.

Tip~/.bashrc — click to expand 
~/.bashrc
# ── Prompt ────────────────────────────────────────────────────────────────────
git_branch() {
    git branch 2>/dev/null | grep '^\*' | sed 's/\* //'
}

# Colors
_reset="\[\e[0m\]"
_bold="\[\e[1m\]"
_red="\[\e[38;5;196m\]"
_orange="\[\e[38;5;214m\]"
_yellow="\[\e[38;5;226m\]"
_green="\[\e[38;5;82m\]"
_blue="\[\e[38;5;75m\]"
_gray="\[\e[38;5;245m\]"

PS1="${_gray}┌─${_reset}"                        # top bar
PS1+="${_bold}${_blue}\u${_reset}"               # username
PS1+="${_gray}@${_reset}"                        # @
PS1+="${_bold}${_orange}\h${_reset}"             # hostname
PS1+="${_gray} in ${_reset}"                     # in
PS1+="${_bold}${_yellow}\w${_reset}"             # working directory
PS1+="\$(git_branch | sed 's/.*/ ${_gray}(${_green}&${_gray})${_reset}/')"  # git branch
PS1+="\n${_gray}└─${_reset} "                   # second line prompt

export PS1

# ── History ───────────────────────────────────────────────────────────────────
HISTSIZE=10000
HISTFILESIZE=20000
HISTCONTROL=ignoredups:erasedups       # no duplicate entries
HISTTIMEFORMAT="%Y-%m-%d %H:%M  "     # timestamp every command
shopt -s histappend                    # append instead of overwrite on exit
PROMPT_COMMAND="history -a"            # write to history immediately

# ── Navigation ────────────────────────────────────────────────────────────────
#shopt -s autocd                        # type a directory name to cd into it
shopt -s cdspell                       # fix minor typos in cd paths
shopt -s dirspell                      # fix minor typos in directory completion

# -- Alias
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'
alias chmod='chmod -v'
alias ls='ls --color=auto'
alias ll='ls -l --color=auto'
alias la='ls -A --color=auto'
alias ..='cd ..'
alias ...='cd ../..'
alias grep='grep --color=auto'
alias more='/usr/bin/less'

export EDITOR=vim

2 vim

vim is a text editor that lives in the terminal. The one idea to grasp is that it has modes: you move around in normal mode and type text in insert mode.

vim system/controlDict     # open (or create) a file
To… do this
start typing press i (enter insert mode)
stop typing press Esc (back to normal mode)
save type :w and Enter
save and quit type :wq and Enter
quit without saving type :q! and Enter

That is genuinely all you need to edit a case file; everything else in vim is a bonus.

2.1 Make vim nicer (optional)

~/.vimrc configures vim: line numbers, sensible indentation, search highlighting and a few handy shortcuts. Create it with vim ~/.vimrc and paste. The persistent-undo option needs its folder, so run mkdir -p ~/.vim/undodir once.

Tip~/.vimrc — click to expand 
~/.vimrc
" ── General ───────────────────────────────────────────────────────────────────
set nocompatible
set encoding=utf-8
set history=1000
set undofile                        " persistent undo across sessions
set undodir=~/.vim/undodir

" ── Appearance ────────────────────────────────────────────────────────────────
syntax on
set number                          " line numbers
set relativenumber                  " relative numbers (great for jumping)
set cursorline                      " highlight current line
set scrolloff=8                     " keep 8 lines above/below cursor
set colorcolumn=80,120              " column rulers
set laststatus=2                    " always show status line
set showmatch                       " highlight matching brackets
set termguicolors

" ── Indentation ───────────────────────────────────────────────────────────────
set tabstop=4
set softtabstop=4
set shiftwidth=4
set expandtab                       " spaces not tabs
set smartindent
set autoindent

" C++ / OpenFOAM often uses different style
autocmd FileType cpp setlocal tabstop=4 shiftwidth=4 expandtab
autocmd FileType c   setlocal tabstop=4 shiftwidth=4 expandtab

" ── Search ────────────────────────────────────────────────────────────────────
set incsearch                       " search as you type
set hlsearch                        " highlight matches
set ignorecase
set smartcase                       " case-sensitive if uppercase used
nnoremap <Esc> :nohlsearch<CR>      " clear highlight with Escape

" ── File handling ─────────────────────────────────────────────────────────────
set autoread                        " reload file if changed outside vim
set noswapfile
set nobackup
set hidden                          " switch buffers without saving

" ── Splits ────────────────────────────────────────────────────────────────────
set splitright                      " new vertical split opens on the right
set splitbelow                      " new horizontal split opens below
nnoremap <C-h> <C-w>h
nnoremap <C-j> <C-w>j
nnoremap <C-k> <C-w>k
nnoremap <C-l> <C-w>l

" ── Useful remaps ─────────────────────────────────────────────────────────────
let mapleader = " "                 " space as leader key

nnoremap <leader>w :w<CR>           " save with space-w
nnoremap <leader>q :q<CR>           " quit with space-q
nnoremap <leader>e :Ex<CR>          " open file explorer

" Move lines up/down with Alt+j/k
nnoremap <A-j> :m .+1<CR>==
nnoremap <A-k> :m .-2<CR>==

" Stay in visual mode after indenting
vnoremap < <gv
vnoremap > >gv

" ── Netrw (built-in file browser) ─────────────────────────────────────────────
let g:netrw_banner    = 0           " hide the banner
let g:netrw_liststyle = 3           " tree view
let g:netrw_winsize   = 25

3 Connecting over SSH (advanced)

NoteFor later

You do not need this for the course: the JupyterLab terminal above is enough. Once command-line access is introduced, you can connect from a terminal on your own machine (macOS/Linux Terminal, or Windows PowerShell / WSL).

3.1 With a password

The simplest way is to log in with the username and password you created during Registration (replace <username> with your cluster username):

ssh <username>@mech501.calculquebec.cloud   # asks for your password each time

3.2 With an SSH key

An SSH key is a pair of files: a private key that never leaves your computer and a matching public key you place on the cluster. The server checks that the two match instead of asking for a password — so you log in without typing one, and it is more secure. Create a key once and copy the public half to the cluster:

ssh-keygen -t ed25519                              # creates ~/.ssh/id_ed25519 (+ .pub)
ssh-copy-id <username>@mech501.calculquebec.cloud  # installs the public key there

From then on the same command logs you straight in, with no password:

ssh <username>@mech501.calculquebec.cloud

3.3 A shortcut: ~/.ssh/config

Save the connection details under a short name in ~/.ssh/config, so you can just type ssh turb:

~/.ssh/config
Host turb
    HostName mech501.calculquebec.cloud
    User <username>
    IdentityFile ~/.ssh/id_ed25519
ssh turb        # uses the HostName, User and key from the block above

Everything above — navigation, viewing files, vim, and the ~/.bashrc / ~/.vimrc setup — works exactly the same over SSH.
